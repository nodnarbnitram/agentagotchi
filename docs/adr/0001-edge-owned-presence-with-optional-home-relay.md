# Edge-owned presence with optional Home relay

Agent Pet assigns one Edge Bridge to each agent machine and makes that Edge authoritative for its Task Presences. Devices may consume direct Edge feeds and one-hop Home-relayed feeds simultaneously; Home provides remote reachability and aggregation without becoming the task authority. We chose this over a single mandatory central bridge, bridge federation, or an Edge mesh so local status survives Home outages, VPS sessions can still reach LAN devices, harness capabilities remain on their owning machines, and routing has no consensus or loop problem. The trade-off is bounded multi-feed connection and merge logic on devices, which must be measured on physical BOX-3 hardware before considering a separate Local Feed Gateway design.
